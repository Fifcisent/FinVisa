# FinVista

Учебный финансовый веб-сервис для управления личными финансами.

## Возможности

- главная страница с описанием сервиса и преимуществ;
- создание индивидуальных демо-профилей, вход и выход; финансовые данные разделены между профилями;
- просмотр email в профиле, смена пароля и переключатель видимости при вводе;
- учет доходов и расходов, просмотр баланса и расходов по категориям;
- демонстрационный портфель с покупкой и продажей инвестиционных активов;
- встроенный в браузер генератор случайной динамики цен акций под влиянием «ветра»;
- создание сберегательных счетов и перевод средств между ними и основным счетом;
- обмен RUB, USD, EUR и CNY по демонстрационным курсам;
- оформление учебного кредита, расчет аннуитетного платежа и внесение платежей.

## Запуск

Это учебный демонстрационный прототип с локальным Python-сервером. Новые профили начинаются с балансом 200 000 RUB и пустыми финансовыми списками; рыночные курсы, ставки и котировки синтетические. Симуляция акций может создавать резкие случайные падения и подъёмы цен. Сервис не подключается к биржам и не выполняет реальные финансовые операции. Данные профилей хранятся в браузере: это не защищенная база данных, и данные не синхронизируются между устройствами. Используйте только вымышленные данные, не вводите реальные пароли или финансовую информацию. Проект не предназначен для незаконной деятельности. Для реального сервиса необходимы серверная база данных, защищенная авторизация и интеграция с лицензированными финансовыми организациями.

Для локального просмотра запустите `py server.py` и откройте `http://127.0.0.1:8000`.

## Публикация через GitHub Pages

Статическая версия сайта работает без Python-сервера и Cloudflare Tunnel: симуляция рынка выполняется в браузере, а `index.html` перенаправляет на главную страницу приложения.

1. Отправьте файлы проекта в репозиторий GitHub. Для общедоступного сайта репозиторий должен быть публичным; его исходный код также будет виден посетителям.
2. Откройте репозиторий на GitHub → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После публикации откройте адрес вида `https://<владелец>.github.io/<репозиторий>/`.

Профили и финансовые записи хранятся только в браузере посетителя и не передаются другим посетителям. GitHub Pages не запускает `server.py`; локальный Python-сервер ниже нужен только для разработки на этом компьютере.

Для временного публичного доступа:

1. Установите `cloudflared` для Windows с [официальной страницы Cloudflare](https://developers.cloudflare.com/tunnel/downloads/). Исполняемый файл должен быть в `PATH` или `%LOCALAPPDATA%\Programs\cloudflared\cloudflared.exe`.
2. Запустите `py public_demo.py`. Email не запрашивается: любой, у кого есть созданная ссылка, сможет открыть сайт.
3. Поделитесь ссылкой `trycloudflare.com`, которую выведет `cloudflared`.
4. Оставьте окно открытым, пока сайт нужен; `Ctrl+C` остановит туннель и сервер.

Сервер слушает только `localhost` — порт не публикуется напрямую и переадресация на роутере не нужна. Quick Tunnel временный: ссылка меняется при новом запуске. Cloudflare может обрабатывать сетевые метаданные; Tailwind CSS и Google Fonts загружаются со сторонних CDN. Данные профиля сохраняются в `localStorage` браузера посетителя и не отправляются серверным API, но это не защищенная серверная база данных. Используйте исключительно вымышленные данные и не вводите реальные персональные или банковские сведения.
